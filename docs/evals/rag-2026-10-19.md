# RAG answers with RAGAs, 2026-10-19

> **Answer:** gpt-oss-20b's answers on main score **faithfulness 0.86** and **answer relevancy 0.80** on 42 of the 94 retrieval questions (RAGAs 0.4.3, claude-haiku-5.5 as judge). Read by hand, 28 of the 260 statements in those answers (11%) really aren't in the passages the agent got: facts from memory, a misread table, one label's line credited to another, a wrong passage cited. The judge's other 14 rejections are its own mistakes. At top_k 10 the label search returns the answer for 85 of 94 questions, against 78 at the current 5, for twice the text. top_k stays at 5 until answers at 10 are measured.

#43 asked for a measure of answer quality next to the retrieval measures we already have (`evals/retrieval/`, [embeddings](../decisions/embeddings.md)). Query translation on vs off, the comparison the issue first named, was already measured in [query translation](query-translation-2026-10-16.md) (#114). The scope was cut to keep the cloud judge to about one run: answer-level metrics only, on a subset, and a top_k comparison scored by script. The baseline is `main` at 728614f.

## Setup

- **Questions:** 42 of the 94 retrieval questions (`backend/evals/datasets/rag_questions.yaml`): from each of the 14 section groups, the 3 whose id has the lowest SHA-256 (`python -m evals.rag.export pick`). No new questions were written or generated, so none needed a review: these were checked by hand for #88.
- **Answers:** the citation eval's answers on main (`data/build/eval/citations/openai_gpt-oss-20b-answer-medium-clean-context-c9a1a2ddf098.jsonl`): `openai/gpt-oss-20b` in LM Studio, 32,768 tokens of context, answer effort medium, `OFFLINE=1`, through `ChatAgent.stream`. The cache key matches main's system prompt and tool descriptions, and the run finished 6 minutes before #279 merged, so no answer was generated for this eval.
- **Contexts:** every label passage the answer's searches returned (a median of 5 per answer, about 7,900 characters), each headed as the agent read it: `[1] Seacall Dexamethasone Ointment. (DEXAMETHASONE), inactive_ingredient: …` (`python -m evals.rag.export answers`).
- **Judge:** `anthropic/claude-haiku-5.5` on OpenRouter, at temperature 0, with up to 16,384 output tokens. Answer relevancy embeds with `openai/text-embedding-3-small`. Neither is the answer model or the app's cloud chat model (gpt-6-luna), so the same judge can score both later. RAGAs 0.4.3 runs in its own uv environment (`evals/rag/judge.py`).
  - **Faithfulness:** the judge splits the answer into statements and decides, for each, whether the contexts support it. The score is the supported share.
  - **Answer relevancy:** the judge writes 3 questions the answer would fit, and the score is their mean cosine similarity to the asked question, or 0 if all 3 call the answer noncommittal.
- **top_k:** every label search in the same cache (99 searches for 94 questions), replayed through `LabelRetriever` with the search text and the checked filter from its retrieval trace, at top_k 3, 5 and 10, no model call (`python -m evals.rag.top_k`). The replay at 5 returned exactly the chunks the cache recorded. A question counts as answered when a kept chunk of its drug holds its evidence.

## What it shows

- **About one statement in nine isn't backed by what the agent read.** That matches [answers from memory](from-memory-2026-10-14.md), where about one answer in five added a fact no passage held. Most of these are true and harmless (warfarin's INR rise "may raise the risk of bleeding"). Two kinds matter more: numbers read from the wrong column of a table, because the chunker flattens tables to a line of text, and a passage from another product's label credited to the one asked about.
- **The judge needs the passage's label name and number.** A first run with bare passage text scored faithfulness 0.79. It rejected "the label lists beeswax among the inactive ingredients of Seacall" because nothing in the text said Seacall, and missed the ZIPSOR/Voltaren and `[2]`/`[1]` mix-ups, which you can only see with names and numbers. With the header the agent reads, 16 answers changed score and the mean went to 0.86.
- **Faithful isn't the same as correct.** "The Imitrex label has no information about animal studies in pregnancy" scores 1.0: none of the 5 passages returned mention animal studies, so the statement is consistent with them. But the label does have them, and the question was written from them. Retrieval missing the passage shows in the retrieval measures and in the citation eval's "evidence returned", not here.
- **Faithfulness and the source check measure the same thing differently.** The source check (#213, `guard/source_check.py`) runs in the app on gpt-oss-20b and judges each claim against the results it cites. Faithfulness judges each statement against everything the answer's searches returned, offline, with a stronger judge. A claim citing the wrong passage fails the source check but can pass faithfulness, unless the statement carries the citation, as the ondansetron ones did. The two numbers aren't independent evidence.
- **Answer relevancy says little here.** Every answer addresses its question; the scores (0.59 to 1.00) mostly reflect how closely the judge's back-written questions match the question's wording. It would catch evasive answers, and there were none.
- **A larger top_k finds more answers but doubles what the model reads.** At 10, 7 more questions get their answering passage. Each search then returns about 15,600 characters instead of 7,700, in a 32k context that also holds earlier results and the system prompt. Whether gpt-oss-20b answers better or gets lost in twice the text needs an answer run at top_k 10, judged the same way; this eval doesn't change top_k.

## Decided along the way

- **RAGAs runs outside the project.** Installing it would downgrade `openai` 3.29 → 3.3 and add langchain-community, datasets, pandas and instructor to the app. The judge script imports nothing from the app and runs with `uv run --no-project --with ragas==0.4.3`. RAGAs' prompts are part of the library, like LangChain's, so they are not in `prompts/`. langchain-community is pinned to 0.4.1, because ragas 0.4.3 imports `chat_models.vertexai`, which 0.4.2 removed. RAGAs sends usage analytics unless `RAGAS_DO_NOT_TRACK` is set; the script sets it.
- **No context precision or context recall.** Both send every passage to the judge and would have tripled the tokens, and they measure retrieval, which the evidence-based recall already measures without a model.
- **The judge's verdicts are kept.** The script runs the steps of `Faithfulness.ascore` itself, so it can save each statement's verdict and the judge's reason. That is what made the hand check above possible.
- **16,384 output tokens.** RAGAs allows 1,024 by default. claude-haiku-5.5 reasons before it answers (2,240 reasoning tokens on one call) and gives a reason per statement, which went past 4,096 on an answer of 15 statements.

## Limits

- One judge run on one set of answers. How much the judge's scores vary between runs isn't measured: the two runs above differ in their contexts, so they can't show it.
- 3 answers per section group, so the per-group means move a lot with one answer: adverse_reactions' 0.66 is mostly the imatinib split mistake.
- The hand check covers only the judge's rejections. Statements it accepted weren't read, so a lenient verdict like the animal-studies one isn't counted.
- The top_k answer key was pooled from embedding models' top 5, so a chunk at rank 6 to 10 that states the answer in other words isn't counted: 0.90 at top_k 10 is a lower bound.
- Cost: 39 of the baseline's 42 answers were judged for $0.12 on the OpenRouter key ($0.0032 per answer), so the run cost about $0.13. The first run with bare passages and two runs that hit the output-token limit cost about $0.14 more; part of that wasn't measured because the runs stopped early.

## Reproduce

```
cd backend
uv run python -m evals.rag.export pick        # only when the subset should change
uv run python -m evals.rag.export answers ../data/build/eval/citations/openai_gpt-oss-20b-answer-medium-clean-context-c9a1a2ddf098.jsonl
uv run --no-project --env-file ../.env --with ragas==0.4.3 --with langchain-community==0.4.1 \
    python evals/rag/judge.py ../data/build/eval/rag/openai_gpt-oss-20b-answer-medium-clean-context-c9a1a2ddf098.samples.jsonl
OFFLINE=1 uv run python -m evals.rag.top_k ../data/build/eval/citations/openai_gpt-oss-20b-answer-medium-clean-context-c9a1a2ddf098.jsonl --top-k 3 5 10
```

To score other answers, make a citation-eval cache with them first (`python -m evals.chat_model.citations`, `OFFLINE=1`) and export that. The judge keeps its scores, with each statement's verdict and reason, in `data/build/eval/rag/<answers>.anthropic_claude-haiku-5.5.ragas-0.4.3-<samples hash>.scores.jsonl`.
